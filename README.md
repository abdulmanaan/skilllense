# SkillLens

**Know what the market wants. See what you're missing.**

SkillLens analyzes thousands of live job postings to show which skills are
actually in demand for each developer role - Backend, Frontend, Mobile,
Data, DevOps, and more. Connect your GitHub account and get a personalized
skill-gap report comparing your repositories against real market demand.

## Why?

Fresh graduates guess what to learn. SkillLens replaces guessing with data.

## Tech Stack

- **Backend:** Python 3.12, FastAPI, SQLAlchemy 2.0, PostgreSQL
- **APIs:** GraphQL (dashboard) + REST (auth), GitHub OAuth
- **Frontend:** React, Vite, Tailwind CSS
- **Tooling:** uv, Git
